Gói Thư Mục .ZIP

Gồm file index.html và tài liệu hướng dẫn kéo thả Netlify chi tiết.

🚀 Hướng dẫn 3 bước kéo thả lên Netlify (30 giây):
  1. Bấm nút "Tải index.html Ngay" ở trên để tải file về máy.
  2. Vào trang web: app.netlify.com/drop.
  3. Kéo thả thư mục chứa file index.html vào vòng tròn giữa màn hình Netlify. Website của bạn sẽ lập tức online với liên kết HTTPS miễn phí!
